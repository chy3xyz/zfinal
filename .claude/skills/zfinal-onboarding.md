# ZFinal — AI Speedrun Onboarding

You are working in a **ZFinal** project. ZFinal is a Zig web framework
optimized for AI-driven development. This skill teaches you the
30-second orientation.

## What ZFinal is

- A high-performance Zig web framework (HTTP server, router, ORM,
  middleware, CSRF, captcha, i18n, metrics, WebSocket, plugins).
- The first Zig web framework designed **AI-first**: the
  `zf` CLI emits machine-readable JSON manifests, generated files
  contain `// ── ai-edit-zone: ...` markers telling you exactly
  where to write business logic, and the in-framework
  `zfinal.ZfTool` lets you call the generator from Zig code.
- Inspired by JFinal (Java) — convention over configuration.

## 30-second orientation

**Path A — SQL / DB primary** (flat CRUD):

```bash
cat schema.sql
zf crud:sql schema.sql --json
# Edit ONLY ai-edit-zone blocks → zf check && zig build test → zig build run
```

**Path B — zent primary** (e-commerce / social graphs — also AI-first):

```bash
cat schema.zent
zf crud:zent schema.zent --json
# Edit ONLY ai-edit-zone in model/persistence/service/handler
# Wire bootstrap → zf check && zig build test
```

Both paths emit machine manifests and `ai-edit-zone` markers. Pick **one** data layer per module.

## Forbidden actions

You MUST NOT:

- Hand-write `model.zig` / `handler.zig` / `service.zig` boilerplate. Use `zf crud:sql`, `zf crud:zent`, or `zf g`.
- Edit generated files outside `// ── ai-edit-zone: ...` blocks.
- Edit `tools/zf/codegen.zig` or `tools/zf/zent_codegen.zig` without running `zig build test-zf` after.
- Edit `src/db/drivers/c_sqlite3.h` (generated by `zig translate-c`).
- Commit `zfinal_migration.zig` (gitignored).
- Run `zig fmt` on `.gen.zig` files (already formatted by the generator).
- Edit the public API in `src/main.zig` without updating `src/generator/generator.zig`.

## Tools you can call

| Tool | What it does |
|------|--------------|
| `zf crud:sql <file> [--json]` | Parse SQL, emit model/service/handler/routes + tests (DB primary) |
| `zf crud:zent <file> [--json]` | Parse `.zent`/`.json`, emit model/persistence/service/handler/routes (zent primary) |
| `zf g handler <Name> [--json]` | Generate a single handler |
| `zf g service <Name> [--json]` | Generate a service skeleton |
| `zf g middleware <Name>` | Generate middleware |
| `zf g task <Name>` | Generate scheduled task |
| `zf new <project_name>` | Create a new ZFinal project from scratch |
| `zf check` | Audit AI boundary compliance |
| `zf version` | Show framework version |
| `zig build` | Compile framework + examples |
| `zig build test` | Run all tests (144+ passing) |
| `zig build test-zf` | Run code generator regression tests |
| `zig build run-<example>` | Run an example (hello, blog, ai-blog-5min, …) |
