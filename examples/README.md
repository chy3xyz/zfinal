# Examples — AI Edit Zone Index

> **Quick reference for AI agents: which files are safe to edit.**

This directory contains runnable ZFinal example applications. Below is the reverse index of every example that has AI-editable code, what each file does, and what AI should NOT touch.

## Index by Example

### `standalone-admin/` (v0.10.8+)
Single-binary admin deployment — `zig build run-standalone-admin`.

| File | AI Edit? | Purpose |
|------|----------|---------|
| `main.zig` | ✅ YES | Routes + HTML template. Embed admin HTML via `@embedFile`. |
| `schema.sql` | ✅ YES | Edit to add/remove tables, then re-run `zf admin`. |
| `public/**/admin.html` | ⚠️ REGEN | Regenerate via `zf admin schema.sql --out public`. Don't hand-edit. |

## Universal Rule

```
✅ AI can edit: main.zig, schema.sql, src/deps.zig, *.ext.zig (ext/ dir)
⚠️ AI must regenerate: *.gen.zig (regen via `zf crud:sql <schema.sql>`)
❌ AI must NOT edit: build.zig, build.zig.zon, anything in vendor/
```

## Quick Check

Run `zf check --ai-zones` from any example directory to get a live list of editable files for that project.

Run `zf check --heal` to auto-patch common compile errors in generated code.
